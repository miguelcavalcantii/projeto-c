Como a corrente funciona
hashn = HMAC-SHA256(chave, dadosn ‖ hashn-1)
hash0 = 000…000 (64 zeros)

O “hash anterior” de cada linha é igual ao “hash” da linha de baixo. Alterar um registro antigo quebra o HMAC dele; apagar uma linha quebra a sequência de ids. Sem a chave (que fica na placa), o invasor não consegue recalcular a corrente.

Limitações (documentadas)

• Apagar o arquivo inteiro só é percebido pela época e por cópias externas (checkpoints, melhoria futura).
• A chave fica na mesma flash: quem copiar a memória inteira pode recalcular a corrente (defesa: Flash Encryption).
• Para demonstrar: no LCD, Auditoria → Sim. ataque e depois Verificar.

O que é o SENTINEL

Smart Embedded Network Threat and Intrusion Logging System: um controle de acesso com ESP32 que une segurança física (crachá RFID + PIN) e segurança digital (detecção de força bruta, bloqueio progressivo e auditoria criptográfica), monitorado por este painel no estilo SOC (Security Operations Center).

Arquitetura em camadas
Comunicaçãotelemetry_manager → painel via USB (Web Serial, JSON por linha)
Segurançasecurity_engine (IDS) · crypto_manager (PBKDF2, HMAC) · event_logger (auditoria)
Regrasmáquina de estados · authentication · user_manager · historico
Hardwaredisplay_manager (LCD) · input_manager (joystick/botão) · rfid_manager (RC522)

Estruturas de dados e algoritmos usados

• Máquina de estados (enum + switch) controla todas as telas.
• Vetor de structs para os usuários, com busca linear O(n) pelo crachá.
• Fila circular com os últimos 10 eventos (inserção O(1)).
• Lista encadeada por hash: cada registro da auditoria aponta para o anterior.
• Busca exaustiva O(10ⁿ): análise de força bruta no laboratório.
